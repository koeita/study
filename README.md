# すうじ つみき（小学校低学年向け 算数×2D物理知育ゲーム）

小学校低学年（1〜2年生）が、遊びながら直感的に算数（たしざん・ひきざん・かけざん・わりざん）を学べる2D物理アクションパズルゲームです。

ブラウザですぐに遊べます（PC・タブレット・スマートフォン対応）。

---

## 🎮 あそびかた

1. **もんだいを みる**
   - 上の黒板に `4 ＋ [ ？ ] ＝ 10` や `8 × 8 ＝ [ ？ ]` などのもんだいが出ます。
2. **すうじを えらんで ポン！**
   - 下の4つのすうじボタンから、こたえのすうじを1回押します。
3. **つみきが おちてきて へんしん！**
   - 上から物理ブロックが落ちてきて、ぶつかって合体・変化します！
     - **たしざん**：合体して大きなつみきに！
     - **ひきざん**：引いた分がカチンと削れてポロリと落ちる！
     - **かけざん**：掛け合わされて一回り大きな特大つみきに倍増！
     - **わりざん**：パカッと左右に半分こ（等分）！
4. **ぜんもん せいかいで 100てん まんてん！**
   - 満点を取ると、大きな赤い「はなまる」スタンプがもらえます！

---

## 🌟 特徴・機能

- **3段階のむずかしさ**：
  - **かんたん**：10までの足し算・引き算、2の段までの掛け算、はんぶんこ（÷2）
  - **ふつう**：くりあがり足し算、くり下がり引き算、4の段までの掛け算、九九の逆割り算
  - **むずかしい**：20超え足し算・引き算、1〜9の段ぜんぶの掛け算、大きめの割り算
- **もんだい数えらび**：3もん（サクッと）・5もん（標準）・10もん（たっぷり）
- **絵本・積み木風デザイン**：目に優しい画用紙色、黒板カラー、丸ゴシックフォント（ひらがな・数字のみ表記）
- **Web Audio API による効果音**：合体音、削り取り音、正解ピンポン音、花丸スタンプ音などすべてブラウザ内でシンセサイズ生成
